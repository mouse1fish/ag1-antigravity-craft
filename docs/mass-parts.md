## 三层三明治

```
外蒙皮铆钉   k=1.0005R
隔热瓦       k=0.992R
内衬板铆钉   k=0.9885R
```

对应真实机身的「蒙皮 / 隔热层 / 内衬板」结构。

## 分布算法

椭球表面按子午弧长分层，每层按椭圆周长（Ramanujan 近似）算环向数量：

```python
nrows = arclen / pitch
for r in range(nrows):
    phi = phi0 + (phi1-phi0)*r/nrows
    circ = ell_circ(HX*sin(phi), HY*sin(phi))
    n = circ / pitch
    off = 0.5 if r % 2 else 0        # 交错
```

## 两端一致性

| 项 | 对齐方式 |
|---|---|
| 弧长积分 | `Np = 4000` |
| 椭圆周长 | Ramanujan |
| 伪随机 | Park-Miller（`16807*s % 2147483647`） |
| 法线 | 椭球梯度归一化 |

## Blender 侧

每族合成一个 mesh（numpy `einsum` 批量算顶点 + `foreach_set` 灌入），
旋转用 Rodrigues 公式把几何 +Z 对齐到实例法线。

| 密度 | 三角面 | 内存 | 渲染 |
|---|---|---|---|
| 15% | 115 万 | 892 MB | 6 s |
| 40% | 307 万 | ~1.5 GB | 9 s |
| 100% | 798 万 | ~3 GB | 不建议 |

## 浏览器侧

`THREE.InstancedMesh`，每族一个 draw call。
默认 25% 密度保证首屏，点「零件满载」切 100%（`instanceMatrix` 约 64 MB）。

## 与真实飞机的差距

| | 本工程 | A380 |
|---|---|---|
| 零件数 | 101 万 | 400 万 |
| 紧固件占比 | 62% | ~75% |
| 系统件 | 数千 | 数十万 |

差距主要在系统件（线束分支树、液压管路、标准件规格）。
下一步最有价值的是把电气网络表展开成真实分支树：
每个连接器 → 每个端子 → 每根导线 → 每个压接点。
