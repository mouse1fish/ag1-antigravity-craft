## 功率链

```
BAT 800V → F1 400A → K1/K2 接触器（K2+R1 50Ω 预充）
  → 母线电容 470µF×4 → 全桥 SiC Q1-Q4
  → Lr 17.5µH + Cr 200nF（串联谐振 85 kHz）
  → 变压器 1:25 → 20 kV
  → CW 6 级倍压 → 240 kV DC
  → 场发射线圈 ×4（L=1.2mH, Q=80）
```

## 仿真方法

不是解析近似，是**状态方程 RK4 积分**：

```
Lr·di/dt = v_ab(t) − v_C − i·R_tot
Cr·dv/dt = i

v_ab(t) = ±800V 方波，85 kHz，死区 350 ns
R_tot = R_eq + ESR，R_eq 按基波匹配取值
```

死区在方波里留真实零电压段，所以功率比理想值低 2.02%（物理正确，不是误差）。

## 3D 细节层次

板体（阻焊）→ 铜皮走线（主干 3.2 mm）→ 焊盘（沉金，185 器件全 pad）
→ 缝合过孔（板边 9 mm 间距 + 内部 22 mm 网格）→ 器件本体
→ 白色丝印框 → 机架 → 线束（8 类）

Z 层次（相对板面）：走线 t+0.02~0.08、焊盘 t+0.060~0.105、
过孔 t+0.060~0.100、器件本体 t+0.112 起。

> 器件必须抬 0.112 mm，否则 68 mm 的接触器会把 3 mm 焊盘完全盖住。
